# k8s-docker-노트
온라인 부트캠프 협업 과정의 학습 기록입니다.

```
개요
```
- 쿠버네티스와 도커를 함께 익히며 정리한 노트.
- 실습 환경: 윈도우 10 + wsl2 / 도커 / 클라우드 관리형 쿠버네티스
```
커리큘럼
```
>- 도커: 1주차부터 9주차까지
>- 쿠버네티스 관리자 과정: 1주차부터 9주차까지
>- 애플리케이션 개발자 과정: 1주차부터 7주차까지


```
주요 실습
```
>- 로그 수집과 모니터링 스택 구성 (4주차 폴더)
>- 클러스터 지표 모니터링 (5주차 폴더)
>- 빌드와 배포 파이프라인 구성 (6주차 폴더)




- 쿠버네티스 위에 올린 간단한 마이크로서비스 예제는 별도 저장소로 분리해 두었습니다.
- 전체 인원 중 일부만 수료했고, 수료증은 원본 저장소의 첨부 파일로 남아 있습니다.
